# tf-d5

Load on the page (importmap for `three` and `three/addons/` must already be in the page head):

```html
<script type="module" src="https://cdn.jsdelivr.net/gh/devinscottfountain/tf-d5@COMMIT/d5/main.js"></script>
```

## Asset credits
- Earth, Moon, Mars color maps: supplied by TerraFirma.
- Earth night lights, clouds, specular, normal: three.js examples (MIT), from NASA imagery (public domain).
- Moon / Mars normal maps: synthesized for this project.
- Star catalog: HYG Database v4.1, David Nash / astronexus (CC BY-SA 4.0).
- Milky Way: Kevinmloch / bsrender, rendered from ESA Gaia EDR3 (ESA/Gaia/DPAC), CC BY-SA 4.0.
- Saturn map + ring strip: James Hastings-Trew, planetpixelemporium.com (free with credit).
